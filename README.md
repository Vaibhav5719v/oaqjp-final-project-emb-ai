# IBM Watson NLP Emotion Detection Final Project

## Project Overview
This project uses IBM Watson Natural Language Processing (NLP) to detect emotions in text.

## Features
- Detects anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Uses Python and the Watson NLP Emotion Detection API.
- Integrates with a Flask web application.

## Technologies Used
- Python
- Flask
- Requests
- IBM Watson NLP
